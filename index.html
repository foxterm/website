Q: 什么是橙狐终端 (FoxTerm)？它主要包含哪些功能？ What is FoxTerm and what core features does it offer?

橙狐终端 (FoxTerm) 是一款专为 Apple macOS 与 iOS 打造的高性能全栈服务器管理 App。它将 SSH 终端、双栏 SFTP 文件传输、Metal 加速 VNC 远控、系统算力实时监控 以及 Docker & Podman 容器集群管理 融为一体。

FoxTerm is an all-in-one, privacy-first server management application built natively for macOS and iOS. It unifies high-performance SSH terminal access, dual-pane SFTP file management, Metal-accelerated VNC remote desktop, real-time system telemetry, and visual Docker/Podman container control.

Q: FoxTerm Pro 订阅如何在 Mac 和 iOS 之间生效？ How does the FoxTerm Pro subscription work across devices?

App 采用免费体验加 Pro 订阅 模式。订阅 FoxTerm Pro 后，同一 Apple ID 下的 macOS 与 iOS/iPadOS 客户端均可同步解锁所有高级特性，并支持通过您的私有 iCloud Container 实现配置无感同步。

FoxTerm is offered as a freemium app with a Pro Subscription option. A single Pro subscription seamlessly grants full access across both macOS and iOS devices tied to your Apple ID, with encrypted configuration sync via your personal iCloud container.

Q: FoxTerm 如何确保服务器密钥与凭据的安全？ How does FoxTerm secure my server keys and connection credentials?

App 严格执行 100% 零遥测策略。所有的凭据与 SSH 私钥均通过硬件级加密隔离存储在 Apple 设备的 Secure Enclave 与 Keychain 中，绝不上报至任何第三方服务器。

FoxTerm operates under a strict zero-telemetry policy with 100% localized data encryption. Server credentials and SSH private keys are hardware-isolated inside Apple Secure Enclave and Keychain, with no data ever sent to third-party servers.

Q: FoxTerm 与 Electron 套壳终端有什么本质区别？ How is FoxTerm different from Electron-based terminal clients?

App 彻底抛弃了沉重的 Electron 网页套壳，完全基于 Native Swift、Metal 硬件加速与 C 原生底层引擎 (OpenSSL, libssh, libvncclient) 打造，拥有极低的内存占用与秒级响应速度。

FoxTerm is not an Electron wrapper. It is engineered from the ground up using Native Swift, Metal hardware acceleration, and C-native libraries, delivering near-instant startup, ultra-low resource usage, and native iOS optimization.
