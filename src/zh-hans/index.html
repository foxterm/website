常见问题

关于 FoxTerm (橙狐终端)，你想知道的一切

安全、Pro 授权与原生性能——一次讲清楚。

问: FoxTerm (橙狐终端) 是什么？它提供哪些核心功能？

FoxTerm (橙狐终端) 是一款为 macOS 与 iOS 原生打造的一体化、隐私优先的服务器管理应用。它整合了高性能的 SSH 终端、 SFTP 文件管理、 Metal 加速 VNC 远程桌面、 实时系统监控，以及可视化的 Docker 与 Podman 容器控制。

问: 免费版与 Pro 有什么区别？Pro 订阅如何跨设备使用？

免费版并非功能阉割的演示版——从 SSH 终端、 SFTP 到 Metal 加速 VNC、实时监控以及 Docker 与 Podman 管理，全部功能完整开放。唯一的限制是可管理的 节点（服务器）数量。订阅 FoxTerm Pro 即可解除该限制、管理无限节点；同一 Apple ID 下的 macOS 与 iOS/iPadOS 客户端同时解锁，配置通过你的私有 iCloud 容器加密同步。

问: FoxTerm (橙狐终端) 如何保护我的服务器密钥与连接凭据？

FoxTerm (橙狐终端) 严格执行零遥测策略，数据 100% 本地加密。服务器凭据与 SSH 私钥被硬件隔离在 Apple 安全隔区与钥匙串 内部，数据绝不会发送到第三方服务器。

问: FoxTerm (橙狐终端) 与基于 Electron 的终端客户端有什么不同？

FoxTerm (橙狐终端) 不是 Electron 套壳。它从零开始采用 原生 Swift、Metal 硬件加速以及 C 语言原生库（OpenSSL、libssh、libvncclient） 构建，启动近乎瞬时、资源占用极低，并针对 iOS 做了原生优化。

问: 支持哪些平台与操作系统？

FoxTerm (橙狐终端) 为 Apple 平台原生打造：运行于 macOS 14.0 及以上、iOS/iPadOS 17.0 及以上，覆盖 iPhone 与 iPad，一次 Universal Purchase 解锁所有设备。没有 Windows、Android 或 Linux 桌面版本——FoxTerm (橙狐终端) 仅为 Apple 原生技术栈而设计。

问: 支持哪些协议与认证方式？

FoxTerm (橙狐终端) 支持 SSH、SFTP 与 VNC 连接，并通过 SSH 管理 Docker 与 Podman 引擎。内置现代加密算法与 Ed25519 等密钥类型、分屏终端会话、命令片段、拖拽式 SFTP 传输，以及容器、镜像与数据卷的可视化管理。

问: FoxTerm (橙狐终端) 会收集数据，或通过它的服务器中转我的连接吗？

不会。FoxTerm (橙狐终端) 从你的设备直连你自己的服务器，绝不代理流量。它严格执行零遥测策略——没有分析、没有活动追踪、没有连接日志。凭据与私钥在设备端加密，并隔离在 Apple Keychain 与 Secure Enclave 内部。

问: 如何在 macOS 上获取 Pro，iOS 又如何激活？

在 macOS 上获取 Pro 有两种方式。 Mac App Store 版是由 Apple 按月或按年扣费的订阅——可在 Apple ID 订阅设置中管理或取消，续订与退款由 Apple 处理。 公证版 是直接分发的已签名 macOS 构建，通过在 pay.foxterm.app 购买的激活码解锁。无论选择哪种 Mac 版本，iOS 应用都会自动激活；iOS 应用本身可在 App Store 免费下载。
