FoxTerm (橙狐终端) 是一款面向 macOS 与 iOS 的原生终端客户端。没有 Electron，没有 Web 包装，没有遥测 —— 只有 Swift 和 C 在做它们最擅长的事。

01 / 为什么选择 FoxTerm

现有的工具不够好，所以我写了一个。

SSH 是基础设施运行的界面。深夜部署、服务器调试、紧急修复，都在这里完成。我试过的每一个客户端，要么停留在 2004 年的感觉，要么对本该原生的功能收取订阅费。

FoxTerm 最初只是一个个人工具 —— 一个真正尊重 macOS 和 iOS 设计语言、运行在原生框架上、不会悄悄回传数据的终端客户端。后来发现，它值得被更多人使用。

没有遥测，没有账号，没有藏在付费墙后面的功能门槛。只是一个做好本职工作的工具。

02 / 工程原则

FoxTerm 的基石 —— 也是绝不退让的底线。

原生优先

Swift 和 C —— 不是 Electron，不是 Web 包装。FoxTerm 直接对话 AppKit 和 UIKit，感觉像是天生就在你的 Mac 和 iPhone 上，而不是从浏览器标签页移植过来的。

架构级隐私

零遥测。连接数据、密钥和会话历史永远不会离开设备。密钥在可用时存放在 Secure Enclave 中 —— 而不是某个云服务器上。

极致性能

冷启动低于 400 毫秒。终端渲染以原生帧率运行。没有 JavaScript 引擎开销，没有启动闪屏，没有人为延迟。

经久耐用

免费下载即可使用全部功能。Pro 版解锁无限节点——支持 App Store 订阅或一次性激活码。没有功能阉割，没有人为分级。 iPad。更新是因为产品在不断变好 —— 不是因为续费日期临近。
