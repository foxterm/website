FoxTerm은 macOS와 iOS를 위한 네이티브 터미널 클라이언트입니다. Electron도, Web 래퍼도, 텔레메트리도 없습니다 — Swift와 C가 본연의 역할을 다할 뿐입니다.

01 / FoxTerm을 선택하는 이유

기존 도구로는 부족했다. 그래서 직접 만들었다.

SSH는 인프라가 작동하는 인터페이스입니다. 심야 배포, 서버 디버깅, 문제 수정 — 모든 것이 여기서 이루어집니다. 시도한 클라이언트는 どれも 2004년에 멈춘 듯하거나 네이티브 기능에 구독료를 요구하고 있었습니다.

FoxTerm은 개인 도구로 시작되었습니다 — macOS와 iOS 디자인 언어를 진정으로 존중하고, 네이티브 프레임워크로 동작하며, 외부로 통신하지 않는 터미널 클라이언트. 그것은 공유할 가치가 있는 것이 되었습니다.

텔레메트리 없음. 계정 없음. 유료 벽 뒤에 숨은 기능 제한 없음. 일을 해내고 방해되지 않는 도구. 그것뿐입니다.

02 / 엔지니어링 원칙

FoxTerm이 기반으로 하는 것 — 그리고 절대 타협하지 않을 것.

네이티브 우선

Swift와 C — Electron도, Web 래퍼도 아닙니다. FoxTerm은 AppKit과 UIKit과 직접 대화하므로, 브라우저 탭에서 옮겨온 것이 아니라 Mac과 iPhone에 태어난 듯한 느낌입니다.

아키텍처에 의한 프라이버시

텔레메트리 제로. 연결 데이터, 키, 세션 기록이 디바이스를 떠나지 않습니다. 키는 가능한 경우 Secure Enclave에 저장됩니다 — 어딘가의 클라우드 서버가 아닌.

퍼포먼스

콜드 런치 400ms 미만. 네이티브 프레임 레이트의 터미널 렌더링. JavaScript 엔진 오버헤드도, 시작 스플래시 화면도, 인위적인 지연도 없습니다.

오래 가도록

다운로드 후 모든 기능을 무료로 사용할 수 있습니다. Pro는 노드 제한을 해제하며, App Store 구독 또는 일회성 활성화 코드로 이용할 수 있습니다. 필수 기능 잠금이나 인위적인 등급 없음. 업데이트는 제품이 계속 좋아지기 때문에 제공되는 것이지, 갱신일이 다가와서가 아닙니다.

04 / 개발자

저는 Swift, Go, React로 작업하는 소프트웨어 엔지니어입니다. FoxTerm은 가장 공들여 만드는 제품입니다 — 모든 코드는 제가 매일 사용하는 도구에서 기대하는 기준으로 작성됩니다.

FoxTerm 외에도 엄선된 수주 프로젝트를 진행합니다 — 기술이 중요하고 기준이 높은 작업. 그런 수준의 관심을 deserve하는 것을 만들고 있다면 연락 주세요.
