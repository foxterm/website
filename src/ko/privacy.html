개인정보 처리방침

최종 업데이트: 2026년 10월

당사의 약속: 제로 텔레메트리

FoxTerm은 서버 인프라, 자격 증명, 워크플로가 오롯이 귀하의 것이라는 원칙 위에 구축되었습니다. 당사는 엄격한 제로 텔레메트리 정책으로 운영되며, 외부 서버에서 귀하의 운영 데이터를 수집, 전송, 저장하지 않습니다.

1. 수집하는 데이터

FoxTerm은 원격 측정 데이터를 전혀 수집하지 않습니다. 구체적으로:

  • 분석, 사용 추적, 행동 모니터링 없음
  • 기본적으로 제3자 서버로 전송되는 크래시 리포트 없음
  • 연결 로그, 명령 기록, 세션 메타데이터 없음
  • 전송되는 IP 주소, 호스트 이름, 서버 지문 없음
  • SSH 키, 비밀번호, 인증 정보가 기기를 떠나는 일이 없음

2. 로컬 데이터 저장 및 암호화

모든 민감 데이터는 Apple의 네이티브 보안 프레임워크를 사용해 오롯이 기기에 저장됩니다:

  • Secure Enclave 보호: SSH 개인 키는 사용 가능한 경우 기기의 Secure Enclave 하드웨어로 암호화되어 보호됩니다
  • 키체인(Keychain) 격리: 자격 증명과 비밀번호는 로컬 iCloud 키체인에 저장되며 Apple 하드웨어 암호화로 암호화됩니다
  • 로컬 설정: 연결 프로필과 설정은 기기에 로컬 저장됩니다. iCloud 동기는 Apple이 종단 간 암호화하는 개인 iCloud 컨테이너를 통해서만 이루어집니다

3. 네트워크 통신

FoxTerm은 귀하가 명시적으로 구성한 서버에만 직접 P2P 연결을 설정합니다:

  • 모든 연결(SSH, VNC, SFTP, Docker/Podman)은 기기에서 귀하의 서버로 직접 연결됩니다
  • 당사는 귀하의 트래픽을 위한 프록시 서버, 릴레이, 중간 서비스를 운영하지 않습니다
  • App Store 거래는 전적으로 Apple이 처리하며, 당사는 결제 정보를 수신하거나 저장하지 않습니다
  • 앱에는 제3자 분석 SDK가 임베디드되지 않습니다

4. iCloud 동기화

iCloud 설정 동기를 켠 경우:

  • 동기화된 데이터는 오롯이 개인 iCloud 계정에 저장되며 당사 서버에는 저장되지 않습니다
  • 동기화 전송은 Apple의 CloudKit 인프라가 전적으로 관리하고 암호화합니다
  • 개인 키는 iCloud를 통해 동기화되지 않습니다; 각 기기의 Secure Enclave에 격리된 상태로 유지됩니다
  • 앱 설정 또는 시스템 iCloud 환경설정에서 언제든 iCloud 동기를 비활성화할 수 있습니다

5. App Store 영수증 검증

Pro 구독 상태 확인을 위해 FoxTerm은 구독 권한을 검증하도록 Apple의 App Store 서버와 통신할 수 있습니다. 이 통신은:

  • 표준 Apple StoreKit API를 통해 처리됩니다
  • Apple 거래 영수증 식별자만 포함합니다
  • 귀하의 서버 데이터, 자격 증명, 사용 정보를 일체 포함하지 않습니다
  • 기기와 Apple 간에 직접 처리되며, FoxTerm 백엔드 서버는 이러한 요청을 로깅하거나 저장하지 않습니다

6. 제3자 서비스

FoxTerm은 어떤 제3자 분석, 광고, 데이터 수집 서비스와도 통합하지 않습니다. 상호작용하는 외부 서비스는 다음뿐입니다:

  • Apple App Store 및 CloudKit 서비스(Apple 개인정보 처리방침의 적용을 받습니다)
  • 귀하가 명시적으로 구성하여 직접 연결하는 SSH, VNC, SFTP, Docker/Podman 서버

7. 아동의 개인 정보

FoxTerm은 13세 미만(또는 귀하 관할 지역의 해당 연령 미만) 아동으로부터 고의로 개인 정보를 수집하지 않습니다. 이 앱은 기술 전문가가 사용하도록 설계된 전문 개발자 도구입니다.

8. 본 방침의 변경

당사는 관행 또는 법적 요건의 변경을 반영하기 위해 본 개인정보 처리방침을 수시로 업데이트할 수 있습니다. 변경 사항은 수정 날짜와 함께 이 페이지에 게시됩니다. 정기적으로 본 방침을 검토하시길 권장합니다.
