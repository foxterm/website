FoxTerm は macOS と iOS のためのネイティブターミナルクライアントです。Electron も、Web ラッパーも、テレメトリもありません —— Swift と C が本来の役割を果たしているだけです。

01 / FoxTerm の理由

既存のツールが十分ではなかった。だから自分で書いた。

SSH はインフラが稼働するインターフェースです。深夜のデプロイ、サーバーのデバッグ、問題の修正 —— すべてここで行われます。試したクライアントはどれも 2004 年から進化していないか、ネイティブでべき機能にサブスクリプションを課していました。

FoxTerm は個人的なツールとして始まりました —— macOS と iOS のデザイン言語を本当に尊重し、ネイティブフレームワークで動作し、ホームに通信しないターミナルクライアント。それは共有する価値のあるものになりました。

テレメトリなし。アカウントなし。ペイウォールの裏に隠れた機能制限なし。 仕事をこなして、邪魔にならないツール。それだけです。

02 / エンジニアリング原則

FoxTerm が基づくもの —— そして決して妥協しないもの。

ネイティブファースト

Swift と C —— Electron でも Web ラッパーでもありません。FoxTerm は AppKit と UIKit と直接対話するため、ブラウザタブから移植されたのではなく、Mac と iPhone に生まれついたような感触です。

アーキテクチャによるプライバシー

テレメトリゼロ。接続データ、鍵、セッション履歴がデバイスから出ることはありません。鍵は利用可能な場合 Secure Enclave に保存されます —— どこかのクラウドサーバーではなく。

パフォーマンス

コールドlaunch 400 ms 未満。ネイティブフレームレートでのターミナルレンダリング。JavaScript エンジンのオーバーヘッドも、起動スプラッシュスクリーンも、人為的な遅延もありません。

長持ちする設計

ダウンロードだけで全機能を利用可能。Pro はノード制限を解除 — App Store サブスクリプションまたはワンタイム activation code で。必須機能をロックせず、不自然な tier もなし。 Mac、iPhone、iPad をカバー。アップデートは製品が良くなり続けるから提供されるのであって、更新日が近づいているからではありません。

04 / 開発者

私は Swift、Go、React で作業するソフトウェアエンジニアです。FoxTerm は最もこだわっているプロダクトです —— すべてのコードは、自分が毎日使うツールに求める基準と同じで書かれています。

FoxTerm 以外にも、厳選された受託プロジェクトを引き受けています —— 技術が重要で、基準が高い仕事。そのレベルの attention に値するものを作っているなら、お気軽に。
