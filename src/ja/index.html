ゼロトラストのセキュリティアーキテクチャ

ローカル暗号化、
完全なデータ主権

サーバーの鍵は、あなたの最も重要な資産です。FoxTerm は、100% ローカルでの暗号化とハードウェア隔離により、厳格なテレメトリゼロを徹底しています。

01 / テレメトリゼロ
テレメトリや活動追跡は一切なし。接続ログがローカル環境から外に出ることはありません。
02 / セキュアエンクレーブ
Apple Keychain と Secure Enclave のハードウェア隔離を活用し、秘密鍵を保管します。
03 / ネイティブ暗号
C ネイティブのエンジンを搭載し、Ed25519 と最新の暗号スイートを完全サポート。
04 / ICLOUD 同期
設定の同期は、専用の暗号化された iCloud コンテナ経由でのみシームレスに行われます。

充実の機能群

現代のサーバー管理に必要なすべてを、ひとつのワークフローに統合。

SSH

高速 SSH

Ed25519 鍵、分割ペインのタブ、コマンドスニペット、ミリ秒単位の応答による賢い自動再接続をサポート。

MON

リアルタイム監視

CPU、メモリ、ディスク I/O、ネットワークスループット、GPU / VRAM メトリクスをアクティブに可視化。

SFTP

2ペイン SFTP

コマンダー式の2ペインで、ドラッグ＆ドロップのファイル転送、アプリ内エディタ、権限制御を備えています。

VNC

Metal 加速 VNC

滑らかなリモートデスクトップアクセスのためのハードウェア加速 VNC エンジン。タッチとジェスチャー向けに調整済み。

CTL

コンテナ管理

コンテナ、イメージ、ボリュームのための視覚的ダッシュボード。Rootless ランタイムとリアルタイムのログストリーミングをサポート。

iOS

ユニバーサル購入

ひとつのサブスクリプションで macOS と iOS / iPadOS の両方をカバー。すべての機能は無料で、ノード数の 上限のみ適用されます。Pro にアップグレードすると、無制限のノードが解放されます。

よくある質問

FoxTerm について知っておくべきすべてのこと

セキュリティ、Pro ライセンス、ネイティブ性能——平易に説明します。

Q: FoxTerm とは何ですか？どのような主要機能がありますか？

FoxTerm は、macOS と iOS のためにネイティブに構築された、オールインワンでプライバシー重視のサーバー管理アプリです。高性能なSSH ターミナル アクセス、 2ペインの SFTP ファイル管理、Metal 加速の VNC リモートデスクトップ、リアルタイムのシステムテレメトリ、視覚的な Docker & Podman コンテナ制御をひとつに統合します。

Q: 無料版と Pro の違いは何ですか？Pro のサブスクリプションはデバイス間でどのように機能しますか？

無料版は機能制限デモではありません。SSH ターミナルや2ペイン SFTP、Metal 加速 VNC、リアルタイム テレメトリ、Docker & Podman 管理に至るまで、すべての機能が完全に 解放されています。唯一の制限は、管理できるノード （サーバー）の数です。FoxTerm Pro に加入するとその上限が外れ、ノード数は無制限になります。また、ひとつのサブスクリプションが、同じ Apple ID の macOS と iOS / iPadOS クライアントの両方を同時に解放し、個人の iCloud コンテナ経由で設定を暗号化して同期します。

Q: FoxTerm はサーバーの鍵や接続認証情報をどのように保護しますか？

FoxTerm は、100% ローカルでのデータ暗号化による厳格なテレメトリゼロのポリシーで動作しています。サーバーの認証情報と SSH の秘密鍵は、Apple Secure Enclave と Keychain 内にハードウェア隔離され、サードパーティのサーバーへデータが送られることは一切ありません。

Q: FoxTerm は Electron ベースのターミナルクライアントと何が違いますか？

FoxTerm は Electron のラッパーではありません。ネイティブ Swift、Metal のハードウェア加速、C ネイティブのライブラリ （OpenSSL、libssh、libvncclient）を使ってゼロから設計されており、瞬時に近い起動、極めて低いリソース 使用、iOS 向けのネイティブ最適化を実現しています。
