ローカル暗号化、
完全なデータ主権

サーバーの鍵は、あなたの最も重要な資産です。FoxTerm は、100% ローカルでの暗号化とハードウェア隔離により、テレメトリを一切行いません。

01 / テレメトリゼロ
テレメトリや活動追跡は一切なし。接続ログがローカル環境から外に出ることはありません。
02 / セキュアエンクレーブ
Apple Keychain と Secure Enclave のハードウェア隔離を活用し、秘密鍵を保管します。
03 / ネイティブ暗号
C ネイティブのエンジンを搭載し、Ed25519 と最新の暗号スイートを完全サポート。
04 / ICLOUD 同期
設定の同期は、専用の暗号化された iCloud コンテナ経由でのみシームレスに行われます。

よくある質問

FoxTerm について知っておくべきすべてのこと

セキュリティ、Pro ライセンス、ネイティブ性能——平易に説明します。

Q: FoxTerm とは何ですか？主な機能は何ですか？

FoxTerm は、macOS と iOS のためにネイティブに構築された、オールインワンでプライバシー重視のサーバー管理アプリです。高性能なSSH ターミナル アクセス、 SFTP ファイル管理、Metal 加速の VNC リモートデスクトップ、リアルタイムのシステムテレメトリ、視覚的な Docker & Podman コンテナ制御をひとつに統合します。

Q: 無料版と Pro の違いは何ですか？Pro のサブスクリプションはデバイス間でどのように機能しますか？

無料版は機能制限デモではありません。SSH ターミナルやSFTP、Metal 加速 VNC、リアルタイム テレメトリ、Docker & Podman 管理に至るまで、すべての機能を完全に ご利用いただけます。唯一の制限は、管理できるノード （サーバー）の数です。FoxTerm Pro に加入するとその上限が外れ、ノード数は無制限になります。また、ひとつのサブスクリプションで、同じ Apple ID の macOS と iOS / iPadOS クライアントの両方を同時にご利用いただけ、個人の iCloud コンテナ経由で設定を暗号化して同期します。

Q: FoxTerm はサーバーの鍵や接続認証情報をどのように保護しますか？

FoxTerm は、100% ローカルでのデータ暗号化による厳格なテレメトリゼロのポリシーで動作しています。サーバーの認証情報と SSH の秘密鍵は、Apple Secure Enclave と Keychain 内にハードウェア隔離され、サードパーティのサーバーへデータが送られることは一切ありません。

Q: FoxTerm は Electron ベースのターミナルクライアントと何が違いますか？

FoxTerm は Electron のラッパーではありません。ネイティブ Swift、Metal のハードウェア加速、C ネイティブのライブラリ （OpenSSL、libssh、libvncclient）を使ってゼロから設計されており、瞬時に近い起動、極めて低いリソース 使用、iOS 向けのネイティブ最適化を実現しています。

Q: どのプラットフォームに対応していますか？

FoxTerm は Apple プラットフォームのためにネイティブに構築されています。macOS 14.0 以降、iOS / iPadOS 17.0 以降で動作し、iPhone と iPad に対応、ひとつの Universal Purchase ですべてのデバイスがアンロックされます。Windows、Android、Linux デスクトップ版はありません——FoxTerm はネイティブ Apple スタック専用に設計されています。

Q: どのプロトコルと認証方式に対応していますか？

FoxTerm は SSH、SFTP、VNC 接続に対応し、SSH 経由で Docker と Podman エンジンを管理します。Ed25519 などの最新の暗号と鍵タイプ、分割ペインターミナルセッション、コマンドスニペット、ドラッグ＆ドロップ SFTP 転送、コンテナ・イメージ・ボリュームの視覚的管理を搭載しています。

Q: FoxTerm はデータを収集したり、接続をサーバー経由でルーティングしたりしますか？

いいえ。FoxTerm はデバイスから直接サーバーに接続し、トラフィックをプロキシすることはありません。厳格なテレメトリゼロのポリシーを適用し、分析、アクティビティ追跡、接続ログは一切ありません。認証情報と秘密鍵はデバイス上で暗号化され、Apple Keychain と Secure Enclave 内に隔離されています。

Q: macOS で Pro を入手するにはどうすればよいですか？iOS のアクティベーションはどのように機能しますか？

macOS で Pro を入手するには2つの方法があります。Mac App Store エディションは、Apple 経由の月額または年額のサブスクリプションです。Apple ID のサブスクリプション設定で管理・キャンセルでき、更新と返金は Apple が処理します。公認版は、pay.foxterm.app で購入したアクティベーションコードでアンロックする、直接配布の署名済み macOS ビルドです。どちらの Mac エディションを選んでも、iOS アプリは自動的にアクティベートされます。iOS アプリ自体は App Store で無料です。
