プライバシーポリシー

最終更新：2026年10月

私たちの約束：テレメトリゼロ

FoxTerm は、あなたのサーバーインフラ、認証情報、ワークフローがあなただけのものであるという原則のもとで構築されています。私たちは厳格なテレメトリゼロのポリシーを運用しており、外部サーバー上であなたの運用データを収集、送信、保存することはありません。

1. 収集するデータ

FoxTerm はテレメトリデータを一切収集しません。具体的には：

  • 分析、使用状況の追跡、行動モニタリングは一切なし
  • クラッシュレポートをデフォルトでサードパーティのサーバーへ送信しない
  • 接続ログ、コマンド履歴、セッションのメタデータは一切なし
  • IP アドレス、ホスト名、サーバーのフィンガープリントを送信しない
  • SSH の鍵、パスワード、認証情報がデバイスから外に出ることは一切ない

2. ローカルデータの保存と暗号化

すべての機密データは、Apple のネイティブセキュリティフレームワークを使い、専らあなたのデバイス上に保存されます：

  • Secure Enclave による保護：SSH の秘密鍵は、利用可能な場合、デバイスの Secure Enclave ハードウェアによって暗号化・保護されます
  • Keychain の隔離：認証情報とパスワードはローカルの iCloud Keychain に保存され、Apple のハードウェア暗号化で暗号化されます
  • ローカル設定：接続プロファイルと設定はデバイス上にローカル保存されます。iCloud 同期は、Apple によってエンドツーエンドで暗号化された、あなた専用の iCloud コンテナ経由でのみ行われます

3. ネットワーク通信

FoxTerm は、あなたが明示的に設定したサーバーに対してのみ、直接ピアツーピア接続を確立します：

  • すべての接続（SSH、VNC、SFTP、Docker / Podman）は、デバイスからあなたのサーバーへ直接行われます
  • あなたのトラフィックのためのプロキシサーバー、リレー、中継サービスは運用していません
  • App Store の取引は Apple によって完全に処理され、私たちは支払い情報を受け取ったり保存したりしません
  • アプリにサードパーティの分析 SDK は組み込まれていません

4. iCloud 同期

iCloud での設定同期を有効にした場合：

  • 同期されたデータは、専らあなた個人の iCloud アカウントに保存され、私たちのサーバーには保存されません
  • 同期の通信は、Apple の CloudKit インフラストラクチャによって完全に管理・暗号化されます
  • 秘密鍵が iCloud 経由で同期されることは一切ありません。各デバイスの Secure Enclave に隔離されたままです
  • iCloud 同期は、アプリの設定またはシステムの iCloud 環境設定から、いつでも無効にできます

5. App Store 領収書検証

Pro サブスクリプションの有効性を確認するため、FoxTerm は Apple の App Store サーバーと通信することがあります。この通信は：

  • 標準的な Apple の StoreKit API 経由で処理されます
  • あなたの Apple の取引領収書の識別子のみを含みます
  • あなたのサーバーデータ、認証情報、使用情報は一切含みません
  • デバイスと Apple の間で直接処理されます。FoxTerm のバックエンドサーバーはこれらのリクエストをログに記録したり保存したりしません

6. サードパーティのサービス

FoxTerm は、サードパーティの分析、広告、データ収集サービスとは連携していません。連携する外部サービスは以下のみです：

  • Apple App Store および CloudKit のサービス（Apple のプライバシーポリシーに準じます）
  • あなたが明示的に設定し、直接接続する SSH、VNC、SFTP、Docker / Podman のサーバー

7. お子様のプライバシー

FoxTerm は、13 歳未満（またはお住まいの地域の適用年齢未満）のお子様の個人情報を意図的に収集することはありません。本アプリは、技術者が業務で使用するプロフェッショナルな開発者向けツールです。

8. 本ポリシーの変更

私たちは、私たちの運用や法的要件の変更を反映するために、このプライバシーポリシーを随時更新することがあります。変更はすべて、改訂日を更新した上でこのページに掲載されます。定期的に本ポリシーをご確認いただくことをお勧めします。

9. お問い合わせ

本プライバシーポリシーや私たちのデータ運用についてご質問やご懸念がある場合は、admin@foxterm.app までご連絡ください。
