FoxTerm is a native terminal client for macOS and iOS. No Electron, no web wrappers, no telemetry — just Swift and C doing exactly what they were designed to do.

01 / WHY FOXTERM

The tools weren't good enough. So I wrote one.

SSH is the interface infrastructure runs on. It's where late-night deploys happen, where servers get debugged, where things get fixed. Every client I tried either felt stuck in 2004 or charged a subscription for features that should be native.

FoxTerm started as a personal tool — a terminal client that actually respects the macOS and iOS design language, runs on native frameworks, and doesn't phone home. It turned into something worth sharing.

No telemetry. No accounts. No feature gates hiding behind paywalls. Just a tool that does the job and gets out of your way.

02 / ENGINEERING PRINCIPLES

What FoxTerm is built on — and what it will never compromise.

Native First

Swift and C — not Electron, not a web wrapper. FoxTerm talks directly to AppKit and UIKit, so it feels like it was born on your Mac and iPhone, not ported from a browser tab.

Privacy by Architecture

Zero telemetry. Connection data, keys, and session history never leave the device. Keys live in the Secure Enclave when available — not on a cloud server somewhere.

Performance

Cold launch under 400 ms. Terminal rendering at native frame rates. No JavaScript engine overhead, no startup splash screens, no artificial delays.

Built to Last

Free to download with all features included. Pro removes the node limit — via App Store subscription or a one-time activation code. No locked-out essentials, no artificial tiers.
