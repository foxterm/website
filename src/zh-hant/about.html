軟體應該
快速、私密、經久耐用。

FoxTerm 是一款面向 macOS 與 iOS 的原生終端機用戶端。沒有 Electron，沒有 Web 包裝，沒有遙測 —— 只有 Swift 和 C 在做它們最擅長的事。

01 / 為什麼選擇 FoxTerm

現有的工具不夠好，所以我寫了一個。

SSH 是基礎設施運作的介面。深夜部署、伺服器除錯、緊急修復，都在這裡完成。我試過的每一個用戶端，要么停留在 2004 年的感覺，要么對本該原生的功能收取訂閱費。

FoxTerm 最初只是一個個人工具 —— 一個真正尊重 macOS 和 iOS 設計語言、運行在原生框架上、不會悄悄回傳資料的終端機用戶端。後來發現，它值得被更多人使用。

沒有遙測，沒有帳號，沒有藏在付費牆後面的功能門檻。只是一個做好本职工作的工具。

02 / 工程原則

FoxTerm 的基石 —— 也是絕不退讓的底線。

原生優先

Swift 和 C —— 不是 Electron，不是 Web 包裝。FoxTerm 直接對話 AppKit 和 UIKit，感覺像是天生就在你的 Mac 和 iPhone 上，而不是從瀏覽器分頁移植過來的。

架構級隱私

零遙測。連線資料、金鑰和作業階段歷史永遠不會離開裝置。金鑰在可用時存放在 Secure Enclave 中 —— 而不是某個雲端伺服器上。

極致效能

冷啟動低於 400 毫秒。終端機渲染以原生幀率運行。沒有 JavaScript 引擎開銷，沒有啟動閃屏，沒有人為延遲。

經久耐用

免費下載即可使用全部功能。Pro 版解鎖無限節點——支援 App Store 訂閱或一次性啟動碼。沒有功能閹割，沒有人爲分級。 iPad。更新是因為產品在不斷變好 —— 不是因為續費日期臨近。
