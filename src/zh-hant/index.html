常見問題

關於 FoxTerm，你想知道的一切

安全、Pro 授權與原生效能——一次講清楚。

Q: FoxTerm 是什麼？它提供哪些核心功能？

FoxTerm 是一款為 macOS 與 iOS 原生打造的一體化、隱私優先的伺服器管理應用程式。它整合了高效能的 SSH 終端機、 SFTP 檔案管理、 Metal 加速 VNC 遠端桌面、 即時系統監控，以及視覺化的 Docker 與 Podman 容器控制。

Q: 免費版與 Pro 有什麼差別？Pro 訂閱如何跨裝置使用？

免費版並非功能殘缺的演示版——從 SSH 終端機、 SFTP 到 Metal 加速 VNC、即時監控以及 Docker 與 Podman 管理，全部功能完整開放。唯一的限制是可管理的 節點（伺服器）數量。訂閱 FoxTerm Pro 即可解除該限制、管理無限節點；同一 Apple ID 下的 macOS 與 iOS/iPadOS 用戶端同時解鎖，設定透過你的私有 iCloud Container 加密同步。

Q: FoxTerm 如何保護我的伺服器金鑰與連線憑證？

FoxTerm 嚴格執行零遙測政策，資料 100% 本地加密。伺服器憑證與 SSH 私鑰被硬體隔離在 Apple Secure Enclave 與 Keychain 內部，資料絕不會傳送到第三方伺服器。

Q: FoxTerm 與基於 Electron 的終端機用戶端有什麼不同？

FoxTerm 不是 Electron 外殼。它從零開始採用 原生 Swift、Metal 硬體加速以及 C 語言原生函式庫（OpenSSL、libssh、libvncclient） 打造，啟動近乎瞬時、資源占用極低，並針對 iOS 做了原生最佳化。

Q: 支援哪些平台與作業系統？

FoxTerm 為 Apple 平台原生打造：執行於 macOS 14.0 及以上、iOS/iPadOS 17.0 及以上，涵蓋 iPhone 與 iPad，一次 Universal Purchase 解鎖所有裝置。沒有 Windows、Android 或 Linux 桌面版本——FoxTerm 僅為 Apple 原生技術棧而設計。

Q: 支援哪些通訊協定與驗證方式？

FoxTerm 支援 SSH、SFTP 與 VNC 連線，並透過 SSH 管理 Docker 與 Podman 引擎。內建現代加密演算法與 Ed25519 等金鑰類型、分割畫面終端機工作階段、指令片段、拖曳式 SFTP 傳輸，以及容器、映像檔與磁碟區的視覺化管理。

Q: FoxTerm 會收集資料，或透過它的伺服器中繼我的連線嗎？

不會。FoxTerm 從你的裝置直連你自己的伺服器，絕不代理流量。它嚴格執行零遙測政策——沒有分析、沒有活動追蹤、沒有連線日誌。憑證與私鑰在裝置端加密，並隔離在 Apple Keychain 與 Secure Enclave 內部。

Q: 如何在 macOS 上取得 Pro，iOS 又如何啟用？

在 macOS 上取得 Pro 有兩種方式。 Mac App Store 版是由 Apple 按月或按年扣費的訂閱——可在 Apple ID 訂閱設定中管理或取消，續訂與退款由 Apple 處理。 公證版 是直接散佈的已簽署 macOS 建構，透過在 pay.foxterm.app 購買的啟用碼解鎖。無論選擇哪種 Mac 版本，iOS app 都會自動啟用；iOS app 本身可在 App Store 免費下載。
