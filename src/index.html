Frequently Asked Questions

Everything You Need to Know About FoxTerm

Security, Pro licensing, and native performance — explained plainly.

Q: What is FoxTerm and what core features does it offer?

FoxTerm is an all-in-one, privacy-first server management application built natively for macOS and iOS. It unifies high-performance SSH terminal access, dual-pane SFTP file management, Metal-accelerated VNC remote desktop, real-time system telemetry, and visual Docker & Podman container control.

Q: What is the difference between the free version and Pro? How does the Pro subscription work across devices?

The free version is not a crippled demo — every capability, from the SSH terminal and dual-pane SFTP to Metal-accelerated VNC, real-time telemetry, and Docker & Podman management, is fully unlocked. The only limit is the number of nodes (servers) you can manage. Subscribing to FoxTerm Pro removes that cap for unlimited nodes, and a single subscription simultaneously unlocks both macOS and iOS/iPadOS clients under the same Apple ID, with encrypted configuration sync via your personal iCloud container.

Q: How does FoxTerm secure my server keys and connection credentials?

FoxTerm operates under a strict zero-telemetry policy with 100% localized data encryption. Server credentials and SSH private keys are hardware- isolated inside Apple Secure Enclave and Keychain, with no data ever sent to third-party servers.

Q: How is FoxTerm different from Electron-based terminal clients?

FoxTerm is not an Electron wrapper. It is engineered from the ground up using Native Swift, Metal hardware acceleration, and C-native libraries (OpenSSL, libssh, libvncclient), delivering near-instant startup, ultra-low resource usage, and native iOS optimization.
