Q: 什么是FoxTerm (橙狐终端)？它主要包含哪些功能？

FoxTerm (橙狐终端) 是一款专为 Apple macOS 与 iOS 打造的高性能全栈服务器管理 App。它将 SSH 终端、双栏 SFTP 文件传输、Metal 加速 VNC 远控、系统算力实时监控 以及 Docker & Podman 容器集群管理 融为一体。

Q: 免费版和 FoxTerm Pro 有什么区别？Pro 订阅如何在 Mac 和 iOS 之间生效？

App 免费版并非功能受限的体验版——SSH、SFTP、VNC、Docker & Podman 等全部功能均已完整开放，唯一限制是节点（服务器）数量上限。订阅 FoxTerm Pro 后即可解除该上限、管理无限节点，同一 Apple ID 下的 macOS 与 iOS/iPadOS 客户端同步解锁，并支持通过您的私有 iCloud Container 实现配置无感同步。

Q: FoxTerm 如何确保服务器密钥与凭据的安全？

App 严格执行 100% 零遥测策略。所有的凭据与 SSH 私钥均通过硬件级加密隔离存储在 Apple 设备的 Secure Enclave 与 Keychain 中，绝不上报至任何第三方服务器。

Q: FoxTerm 与 Electron 套壳终端有什么本质区别？

App 彻底抛弃了沉重的 Electron 网页套壳，完全基于 Native Swift、Metal 硬件加速与 C 原生底层引擎 (OpenSSL, libssh, libvncclient) 打造，拥有极低的内存占用与秒级响应速度。
